# VMSL frontend

React + TypeScript + Vite + Tailwind. See the [root README](../README.md) for complete setup, architecture and validation instructions.

```bash
npm ci
npm run dev
npm run lint
npm run build
```

`VITE_API_BASE_URL` selects the API origin at build time (default `http://127.0.0.1:8000`). See `.env.example`. No credentials are required.
